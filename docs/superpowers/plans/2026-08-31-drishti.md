# DRISHTI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page Next.js demonstration instrument that shows three navigation estimators tracking one vehicle through a GNSS blackout, where naive INS visibly collapses and DRISHTI stays road-constrained.

**Architecture:** A pure-TypeScript simulation core (`lib/sim/`, zero React imports) steps physics at a fixed 100 Hz accumulator and publishes snapshots at ~20 Hz. Trajectory geometry is written imperatively to SVG element refs inside the rAF callback so React never reconciles 33k points; numeric panels subscribe via `useSyncExternalStore`. One component tree renders both presentation and technical density, driven by a single `uiMode` state.

**Tech Stack:** Next.js 15 (App Router), TypeScript, Tailwind v4, framer-motion (state transitions only), Vitest. No map library, no backend, no API keys, no network at runtime.

**Spec:** `docs/superpowers/specs/2026-08-31-drishti-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- `Math.random()` must appear nowhere in `lib/sim/`. All randomness flows through the seeded `Rng`.
- `DEFAULT_SEED = 26168`. Two consecutive RESET -> RUN cycles must produce identical final numbers.
- No numeric literal in a metric slot in JSX. Sole carve-out: `CHI2_2DOF_99 = 9.21` and `TARGET_ERROR_FRACTION = 0.10` are method constants defined in `lib/sim/constants.ts` and rendered from there.
- Zero network after load: no `fetch`, no WebSocket, no external images, no CDN, no map tiles, no analytics, no `next/font/google`. System font stacks only.
- The speed estimator is labelled `SPEED MODEL (SIMULATED)` everywhere. Never "trained model". No training accuracy is ever displayed.
- The 10% threshold is labelled `TARGET`. Never `ACHIEVED`, never `VALIDATED`.
- The words "accuracy", "validated", and "proven" appear on no screen. No results table.
- The error/distance metric is never clamped, even when it exceeds TARGET.
- The header RUNTIME block and the honesty footer are always present and non-dismissible.
- Every animation must trace to a variable in `lib/sim/`. If it cannot, delete it.
- Palette, typography, and spacing exactly as specified in spec section 6. All numerals mono with `font-variant-numeric: tabular-nums`.

### Task 2: Seeded RNG

**Files:**
- Create: `lib/sim/rng.ts`
- Test: `tests/sim/rng.test.ts`

**Interfaces:**
- Consumes: nothing.
- Produces:
```ts
export class Rng {
  constructor(seed: number)
  next(): number                              // uniform [0,1)
  gaussian(mu?: number, sigma?: number): number
}
export function makeAr1(rng: Rng, sigma: number, rho: number): () => number
```
`makeAr1` returns a closure holding its own previous value; each call advances the AR(1) process `x = rho*x + sqrt(1-rho^2)*gaussian(0, sigma)`.

- [ ] **Step 1: Write failing tests**

```ts
import { describe, it, expect } from 'vitest'
import { Rng, makeAr1 } from '../../lib/sim/rng'

describe('Rng', () => {
  it('is deterministic for a given seed', () => {
    const a = new Rng(26168), b = new Rng(26168)
    const ra = Array.from({ length: 500 }, () => a.next())
    const rb = Array.from({ length: 500 }, () => b.next())
    expect(ra).toEqual(rb)
  })

  it('differs across seeds', () => {
    expect(new Rng(1).next()).not.toEqual(new Rng(2).next())
  })

  it('stays in [0,1)', () => {
    const r = new Rng(7)
    for (let i = 0; i < 10000; i++) {
      const v = r.next()
      expect(v).toBeGreaterThanOrEqual(0)
      expect(v).toBeLessThan(1)
    }
  })

  it('produces gaussians with the requested moments', () => {
    const r = new Rng(3)
    const n = 200000
    let sum = 0, sumSq = 0
    for (let i = 0; i < n; i++) { const v = r.gaussian(2, 3); sum += v; sumSq += v * v }
    const mean = sum / n
    const sd = Math.sqrt(sumSq / n - mean * mean)
    expect(mean).toBeCloseTo(2, 1)
    expect(sd).toBeCloseTo(3, 1)
  })

  it('AR(1) is correlated and bounded', () => {
    const step = makeAr1(new Rng(11), 0.35, 0.9)
    const xs = Array.from({ length: 5000 }, step)
    const sd = Math.sqrt(xs.reduce((a, x) => a + x * x, 0) / xs.length)
    expect(sd).toBeGreaterThan(0.2)
    expect(sd).toBeLessThan(0.55)
    // lag-1 correlation should be near rho
    let num = 0
    for (let i = 1; i < xs.length; i++) num += xs[i] * xs[i - 1]
    expect(num / (xs.length * sd * sd)).toBeGreaterThan(0.7)
  })
})
```

- [ ] **Step 2: Run and confirm failure.**

- [ ] **Step 3: Implement a three-pass speed profile**

1. **Ceiling pass:** for each 1 m station, `vMax = min(segment.speedLimit, sqrt(A_LAT_MAX / |k|))` with `A_LAT_MAX = 2.2`. Force `vMax = 0` in a 1 m window at `INTERSECTION_S`.
2. **Forward pass:** limit acceleration to `A_ACCEL = 1.75` (this is what gives 0->14 m/s in 8 s).
3. **Backward pass:** limit deceleration to `A_DECEL = 2.5`, so the vehicle brakes *before* turns and the stop rather than after.

Then integrate time forward at `dt`, inserting a 4 s dwell at the stop station. `omega = v * curvatureAt(s)`, `aLong = dv/dt`.

- [ ] **Step 3: Implement exactly the equations in spec section 4.1**

advance(wallDtMs: number) {
  if (!this.running) return
  this.acc += Math.min(wallDtMs, 250) / 1000
  let steps = 0
  while (this.acc >= this.dt && steps < MAX_STEPS_PER_FRAME) {
    this.step(); this.acc -= this.dt; steps++

### Task 18: Final verification against acceptance criteria

- [ ] **Step 1: Automated audit test**

```ts
import { describe, it, expect } from 'vitest'
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { join } from 'node:path'

function walk(dir: string): string[] {
  return readdirSync(dir).flatMap(f => {
    const p = join(dir, f)
    return statSync(p).isDirectory() ? walk(p) : [p]
  })
}
const src = () => [...walk('app'), ...walk('components')].filter(f => /\.tsx?$/.test(f))

describe('acceptance', () => {
  it('makes no forbidden claims anywhere in the UI', () => {
    for (const f of src()) {
      const t = readFileSync(f, 'utf8')
      expect(t).not.toMatch(/\bvalidated\b/i)
      expect(t).not.toMatch(/\bproven\b/i)
      expect(t).not.toMatch(/\baccuracy\b/i)
      expect(t).not.toMatch(/trained model/i)
    }
  })

  it('never labels the target as achieved', () => {
    for (const f of src()) expect(readFileSync(f, 'utf8')).not.toMatch(/ACHIEVED/)
  })

  it('makes no network calls', () => {
    for (const f of src()) {
      const t = readFileSync(f, 'utf8')
      expect(t).not.toMatch(/\bfetch\s*\(/)
      expect(t).not.toMatch(/new WebSocket/)
      expect(t).not.toMatch(/next\/font\/google/)
      expect(t).not.toMatch(/https?:\/\/(?!www\.w3\.org)/)
    }
  })
})
```
